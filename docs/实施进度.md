## 当前版本

- `nekoray_version.txt` 为唯一版本源（CI `libs/check_version.sh` 强制与
  pubspec、`CoreVersion` 一致）。
- 架构：Flutter 瘦客户端 + Go/sing-box core，gRPC 为唯一通信接口。详见
  `docs/ARCHITECTURE.md`，决策见 `docs/DECISIONS.md`。

## 已知限制

1. 更新包无发布者签名（详见 `docs/SECURITY.md`）。
2. 订阅无自动定时更新，只有手动"更新全部订阅"。
3. TUN 在虚拟机/受限容器可能不可用；移动端 TUN 未实现。
4. 故障排查见 `docs/TROUBLESHOOTING.md`。
